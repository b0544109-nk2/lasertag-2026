## しくみ

| | どうやって |
|---|---|
| 読む | Googleスプレッドシートの「記録」タブ（リンクを知っている全員が閲覧可）を gviz で読む |
| 書く | 入力ページがGoogleフォームに裏で送信 →「記録」タブに1行ふえる |
| 公開 | GitHub Pages（main ブランチ） |

「記録」タブの行は消さない・直さない。同じ試合・同じチームは、いちばん新しい行が正。

## ファイル

- `index.html` … 見るページ（あんない／進行／対戦表／チーム のタブ）
- `nyuryoku.html` … チーム名・メンバー・スコアの入力ページ
- `data.js` … ルール・試合順・タイムテーブル（`DEFAULT_ROWS`）と読み書きの共通部分
- `config.js` … シートIDとフォームの送信先。空のあいだは「おためし」（入力はその端末の中だけ）
- `setup.gs` … シートとフォームを作る Apps Script（1回だけ実行）

## 気をつけること

- タブの名前「記録」とフォームの質問の文言は変えない
- 入力ページはURLを知っていれば誰でも書きこめる。幹事とお手伝いの人だけに教える
- 試合の並び（`DEFAULT_ROWS` の「試合」行）は、スコアを入れはじめたら変えない（スコアは並び順の番号にひもづく）
- シートは誰でも読める。名前とスコア以外は書かない
